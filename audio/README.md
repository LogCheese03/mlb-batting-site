# Umpire call recordings

Put recordings here and the site plays them instead of the computer voice (which is the fallback for any file that is missing).
Use these exact names; `.mp3`, `.m4a` (what Voice Memos on an iPhone saves), `.wav` or `.ogg` all work.

| File name | What to say | Used in |
|---|---|---|
| `umpire-ball` | "Ball!" | strikeout scene, each ball |
| `umpire-strike` | "Strike!" | strikeout scene, strikes one and two |
| `umpire-strike-three` | "Strike three! ... You're out!" | strikeout scene, the last pitch |
| `umpire-safe` | "Safe!" | stolen base and triple scenes |
| `umpire-home-run` | "Home run!" | home run scene |

Tips: record in a quiet room, say it loudly like a real umpire, and trim the silence at the start so the call lands on time.
Keep each clip under about 2 seconds. Only record your own voice or use clips you have the right to share.
